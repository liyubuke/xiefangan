写方案 · 安装本机服务

写方案是一个 Edge 插件：在飞书 / i讯飞文档里选中文字，交给你电脑上的 Claude Code、Codex 或 WorkBuddy，结合全文、表格和图片给出可直接复制的改法。插件需要一个只在本机运行的小服务来调用这些工具，一行命令，约 30 秒装好（支持 macOS 和 Windows）。

macOS在「终端」里运行

curl -fsSL https://liyubuke.github.io/xiefangan/install.sh | bash

前提：已装好 Claude Code、Codex、WorkBuddy 中至少一个，并能在终端里正常使用。

三步装好

  1. 打开「终端」：按 ⌘ + 空格，输入「终端」后回车。
  2. 点上面「复制命令」，在终端窗口里粘贴（⌘ + V），按回车。
  3. 看到「✓ 装好了，回到 Edge 侧边栏即可使用」后，回到 Edge 打开写方案侧边栏，右上角圆点变绿就能用了。

Windows在「Windows PowerShell」里运行

irm https://liyubuke.github.io/xiefangan/install.ps1 | iex

前提：Windows 10（1803 及以上）或 Windows 11；已装好 Claude Code、Codex、WorkBuddy 中至少一个。不需要管理员权限，也不用另装 Node.js（缺的话会自动下载便携版）。

三步装好

  1. 打开 PowerShell：点「开始」菜单（或按 Win 键），输入「PowerShell」，点「Windows PowerShell」打开。不用选「以管理员身份运行」。
  2. 点上面「复制命令」，在 PowerShell 窗口里单击右键（或按 Ctrl + V）粘贴，按回车。
  3. 看到「√ 装好了，回到 Edge 侧边栏即可使用」后，回到 Edge 打开写方案侧边栏，右上角圆点变绿就能用了。

还没装插件？去 Edge 应用商店安装写方案

常见问题

macOS这个命令做了什么？
  • 把本机服务下载到 ~/Library/Application Support/XieFangAn；
  • 注册一个登录后自动运行的后台服务（com.xiefangan.bridge），只监听本机 127.0.0.1:19930，外网和局域网都访问不到；
  • 服务只接受写方案插件发来的请求，普通网页调不动它。

可以先在浏览器里打开 install.sh 看完脚本内容再运行。可重复运行，重装不影响已有设置。

Windows这个命令做了什么？
  • 把本机服务下载到 %LOCALAPPDATA%\XieFangAn（日志在其中的 logs\bridge.log）；
  • 电脑里没有 Node.js 18 以上时，从 npmmirror.com（不通再用 nodejs.org）下载官方便携版，校验后放在同一个目录里，不改系统设置；
  • 在「启动」文件夹放一个 XieFangAn.vbs，登录后在后台（不弹窗口）运行服务，只监听本机 127.0.0.1:19930，外网和局域网都访问不到；
  • 服务只接受写方案插件发来的请求，普通网页调不动它。不需要管理员权限。

可以先在浏览器里打开 install.ps1 看完脚本内容再运行（脚本里的中文提示按 base64 存放，避免 PowerShell 乱码）。可重复运行，重装不影响已有设置。

我选中的文字会发到哪里？

插件 → 你电脑上的本机服务 → 你自己电脑上的 Claude Code / Codex / WorkBuddy。不经过写方案的任何服务器；各工具如何处理内容，以它们各自的服务条款为准。详见隐私政策。

提示「一个都没找到」

说明终端（Windows 上是 PowerShell）里找不到 claude、codex 命令，也没装 WorkBuddy。先装好其中一个，确认在终端里输入 claude（或 codex）能正常对话，再运行一次安装命令。Windows 上刚装完的工具，要关掉 PowerShell 窗口重新打开才认得到。

macOS提示「没找到 Node.js 18 以上」

到 nodejs.org 下载 LTS 版安装，或在终端运行 brew install node，然后再运行一次安装命令。装了 WorkBuddy 的电脑会自动借用它自带的 Node.js。

装好了，侧边栏还是提示「还差一步」/ 圆点是红的
  • 点侧边栏里的「我装好了，重新检测」；
  • 到 edge://extensions/ 找到写方案，点「重新加载」；
  • 再运行一次安装命令；仍不行就看日志：
tail -50 ~/Library/Logs/xiefangan-bridge.log
Get-Content "$env:LOCALAPPDATA\XieFangAn\logs\bridge.log" -Tail 50 -Encoding UTF8
Windows怎么确认本机服务在运行？

按 Ctrl + Shift + Esc 打开任务管理器，在「详细信息」里能看到 node.exe（还有一个后台的 powershell.exe，它负责服务意外退出后 3 秒内自动重启）。也可以在 PowerShell 里运行下面这行，有输出就说明在运行：

Get-CimInstance Win32_Process -Filter "Name='node.exe'" | Where-Object CommandLine -like '*XieFangAn*' | Select-Object ProcessId, CommandLine

重启电脑后服务会自动运行；如果没有，再运行一次安装命令即可。

Windows公司电脑的杀毒软件拦截了 / 运行命令后报错
  • 杀毒软件（如 360、火绒、公司终端安全软件）可能拦截「从网上下载并运行脚本」，或拦截「启动」文件夹里新增的 XieFangAn.vbs。在杀毒软件的提示里选「允许」/「信任」，再运行一次安装命令；
  • 拦截后没有提示的，到杀毒软件的「隔离区」/「信任区」把 %LOCALAPPDATA%\XieFangAn 和「启动」文件夹里的 XieFangAn.vbs 加入信任；
  • 公司统一管理的电脑如果禁止运行脚本，请联系公司 IT 放行 PowerShell 脚本，或换一台电脑使用；
  • 报错里有「端口 19930 被别的程序占用」：关掉占用它的程序（报错里写了程序名），再运行一次安装命令。
Codex / WorkBuddy 提示没登录

插件会自动弹出登录页（WorkBuddy 会打开一个终端登录窗口），按提示登录后点「重试」。Codex 也可以在终端运行 codex login。

怎么卸载？

macOS在终端运行下面这行（会停止并删除本机服务、日志和 /tmp/xiefangan 下的临时图片），再到 edge://extensions/ 移除写方案插件：

curl -fsSL https://liyubuke.github.io/xiefangan/uninstall.sh | bash

Windows在 Windows PowerShell 运行下面这行（会停止并删除本机服务、%LOCALAPPDATA%\XieFangAn（含日志和自动下载的 Node.js）、「启动」文件夹里的 XieFangAn.vbs，以及 %TEMP%\xiefangan、%TEMP%\xfa-login 下的临时文件），再到 edge://extensions/ 移除写方案插件：

irm https://liyubuke.github.io/xiefangan/uninstall.ps1 | iex
