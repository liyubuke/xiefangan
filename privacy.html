「写方案」隐私政策

适用于 Microsoft Edge 插件「写方案」及其配套本机服务　·　生效日期：2026-11-20（本次更新：新增 Windows 支持）

中文English
一句话说明：插件只在你主动触发时读取你选中的文档内容，只发给你自己电脑上的本机服务（127.0.0.1）；本机服务再调用你自己安装并登录的 AI 命令行工具，由该工具把内容发给你选择的 AI 服务商处理。插件没有自己的服务器，不做统计，不出售数据，不修改你的文档。

1. 插件是做什么的

「写方案」是一个 Microsoft Edge 浏览器插件。你在飞书 / Lark 网页文档中选中一段文字后，插件把这段文字和它所在文档的上下文交给你电脑上的 AI 命令行工具（Claude Code、Codex 或 WorkBuddy / CodeBuddy，三选一，由你在侧边栏选择），并在侧边栏显示可复制的修改建议。

插件由两部分组成：

  • 浏览器插件：在 Edge 里运行，负责读取选区和显示结果。
  • 本机服务：你用一行命令安装在自己电脑（macOS 或 Windows）上的小程序，只监听本机回环地址 127.0.0.1:19930，其他电脑访问不到，且只接受本插件发来的请求。它负责调用你电脑上的 AI 命令行工具。

2. 会读取哪些数据

只有在你主动触发时（点选区旁的「写方案」按钮、右键菜单、快捷键，或在侧边栏点「改选中的」），插件才会读取当前这一篇文档的以下内容：

  • 你选中的文字；
  • 文档标题和网页地址；
  • 文档全文及结构（标题层级、列表、表格）；文档较长（约 2 万字以上）时，只取大纲和选区前后的部分；
  • 文档中已加载的嵌入电子表格内容（每张最多 100 行 × 30 列）；
  • 选区所在小节和前后附近的图片，最多 8 张（长边不超过 1920 像素）；
  • 你在侧边栏输入的要求和追问。

图片是在文档页面内、以你当前已登录的文档会话下载的，插件不会读取你的 Cookie、登录令牌或密码。

插件不会读取：你的浏览历史、其他标签页、其他网站的内容、表单输入、键盘输入记录、位置信息。文档页面上的插件脚本只用来在你选中文字时显示一个浮动按钮，它监听的选区变化、滚动和 Esc 键只用于显示 / 隐藏按钮，不记录也不发送。

3. 数据怎么使用、发往哪里

环节发生了什么
浏览器插件 → 本机服务上面第 2 节的内容通过 http://127.0.0.1:19930 发给你电脑上的本机服务。这一步不经过互联网。
本机服务 → AI 命令行工具本机服务把图片临时保存到你电脑的临时目录（macOS 为 /tmp/xiefangan/，Windows 为 %TEMP%\xiefangan\），然后在你的电脑上启动你所选的 AI 命令行工具，并把文档内容和处理要求交给它。
AI 命令行工具 → AI 服务商AI 命令行工具使用你自己的账号，把内容发送给你登录的 AI 服务商（例如 Anthropic、OpenAI、腾讯等）生成修改建议。这部分数据如何传输、保存和使用，由该服务商的服务条款和隐私政策决定，与本插件无关。
结果返回修改建议从 AI 工具 → 本机服务 → 侧边栏显示。是否复制使用由你决定。

这些数据只用于完成你这一次的改写请求，不用于任何其他目的。

需要你知道的几点：

  • AI 命令行工具按你自己的配置运行。它可能按其自身能力读取你电脑上与任务相关的文件（例如你给它配置的记忆或说明文件），也可能进行联网搜索来核对信息，与你平时在终端（macOS）或 PowerShell（Windows）里使用它时一致。本机服务以只读沙箱方式运行 Codex，对 WorkBuddy 只开放读取、搜索和联网检索类工具；Claude Code 沿用你本机 Claude Code 的权限设置。
  • 首次使用 Codex 或 WorkBuddy 且尚未登录时，本机服务会帮你打开该工具官方的登录页面或登录窗口；登录过程由该工具自己完成，插件和本机服务不接触你的账号密码。

4. 数据存在哪里、存多久

  • 本机服务程序：安装命令把本机服务（一个 Node.js 脚本、规则文件和本机配置）放在 macOS 的 ~/Library/Application Support/XieFangAn/，并注册为登录后自动运行的 launchd 服务（~/Library/LaunchAgents/com.xiefangan.bridge.plist）；在 Windows 上放在 %LOCALAPPDATA%\XieFangAn\，并在「启动」文件夹里放一个 XieFangAn.vbs 让它登录后自动在后台运行。卸载命令会把它们全部删除。
  • 浏览器本地存储（chrome.storage.local）：只保存两项偏好——你选的 AI 工具和每个工具选的模型。
  • 浏览器会话存储（chrome.storage.session）：刚读取到的选区内容会短暂放在这里，交给侧边栏后立即清除；关闭浏览器时也会自动清除。
  • 本机临时图片：macOS 保存在 /tmp/xiefangan/，Windows 保存在 %TEMP%\xiefangan\（都按文档分文件夹）。macOS 会定期或在重启时清理；Windows 可用系统的「磁盘清理」清除。你也可以随时手动删除。
  • 本机服务日志：macOS 保存在 ~/Library/Logs/xiefangan-bridge.log，Windows 保存在 %LOCALAPPDATA%\XieFangAn\logs\bridge.log，只记录请求时间、所用 AI 工具、文档编号和你输入要求的前 40 个字，以及连接检测的来源（请求方式、来源插件标识、是否通过校验），用于排查故障，不发送给任何人。
  • WorkBuddy 登录脚本：选用 WorkBuddy 且尚未登录时，本机服务会生成一个登录用的小脚本（macOS 在 /tmp/xfa-login/，Windows 在 %TEMP%\xfa-login\），只含启动登录的命令，不含账号信息。
  • AI 工具自己的记录：你所用的 AI 命令行工具可能按它自己的方式在你电脑上保存对话记录（用于追问续接），也可能由服务商按其政策保存。这部分请参考对应工具和服务商的说明。

开发者没有服务器，不会收到、也不保存你的任何文档内容或使用数据。

5. 是否分享给第三方

  • 开发者不向任何第三方出售、出租、交易或分享你的数据。
  • 插件不使用任何统计、广告、崩溃上报或追踪服务。
  • 唯一的对外传输，是你主动触发后，由你自己安装和登录的 AI 命令行工具发给你自己选择的 AI 服务商，这是插件功能本身所必需的。如果你不希望某段内容发给 AI 服务商，请不要对它使用本插件。
  • 安装或卸载本机服务时，你的电脑会从托管安装脚本的网站（GitHub Pages）下载脚本和本机服务程序；该网站可能按 GitHub 的隐私政策记录访问日志（如 IP 地址）。插件本身在使用过程中不会访问该网站。
  • 第三方下载（仅 Windows、仅在需要时）：在 Windows 上安装时，如果电脑里没有可用的 Node.js（本机服务运行所需），安装命令会从 npmmirror.com 或 nodejs.org 下载 Node.js 官方发布的便携版（zip 包，不改系统设置、不需要管理员权限），仅供本机服务使用。下载时这两个网站可能按其自身政策记录访问日志（如 IP 地址）。除此之外不会下载其他第三方软件；macOS 上不会自动下载 Node.js。

6. 你可以如何控制和删除数据

  • 不触发就不读取：插件不会自动读取文档，每次都需要你主动操作。
  • 停用或卸载插件：在 edge://extensions/ 关闭或移除「写方案」，浏览器中保存的偏好会随之删除。
  • 卸载本机服务：
    • macOS：在「终端」运行网站上提供的卸载命令（curl -fsSL https://liyubuke.github.io/xiefangan/uninstall.sh | bash），会停止并删除本机服务、开机自启项、日志、/tmp/xiefangan/ 下的临时图片和 /tmp/xfa-login/ 下的登录脚本。
    • Windows：在「Windows PowerShell」运行 irm https://liyubuke.github.io/xiefangan/uninstall.ps1 | iex，会停止并删除本机服务、%LOCALAPPDATA%\XieFangAn\（含日志和安装时下载的 Node.js 便携版）、「启动」文件夹里的 XieFangAn.vbs、%TEMP%\xiefangan\ 下的临时图片和 %TEMP%\xfa-login\ 下的登录脚本。
  • 手动删除临时图片：macOS 在「终端」运行 rm -rf /tmp/xiefangan；Windows 在 PowerShell 运行 Remove-Item -Recurse -Force "$env:TEMP\xiefangan"。
  • AI 服务商侧的数据：请按对应 AI 工具和服务商提供的方式查看或删除。

7. 安全

  • 本机服务只监听 127.0.0.1，不对局域网或互联网开放，并且只接受本插件发来的请求，普通网页无法调用它。
  • 插件不加载任何远程代码，全部代码随插件包发布、未经混淆。
  • 插件只读文档，不修改、删除或写回你的文档。

8. 未成年人

本插件面向办公写作场景，不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

9. 政策变更

如果插件的数据处理方式发生变化，我们会在插件更新前同步更新本页面，并修改顶部的生效日期。

Privacy Policy — 写方案

Applies to the Microsoft Edge extension "写方案" and its companion local service · Effective date: 2026-11-20 (this update: Windows support added)

In short: the extension reads the document content you select only when you trigger it, and sends it only to a companion service on your own computer (127.0.0.1). That service runs the AI command-line tool you installed and signed in to, and that tool sends the content to the AI provider you chose. The extension has no server of its own, does no analytics, never sells data, and never modifies your documents.

1. What the extension does

"写方案" is a Microsoft Edge extension. When you select text in a Feishu / Lark web document, it passes the selection and its document context to an AI command-line tool on your computer (Claude Code, Codex, or WorkBuddy / CodeBuddy — you choose one in the side panel) and shows copy-ready rewrite suggestions in the side panel.

It has two parts:

  • The browser extension, which runs in Edge, reads the selection and displays results.
  • The companion service, a small program you install on your own computer (macOS or Windows) with one command. It listens only on the loopback address 127.0.0.1:19930, cannot be reached from other machines, and only accepts requests from this extension. It runs the AI command-line tool on your computer.

2. Data the extension reads

Only when you explicitly trigger it (the "写方案" button next to the selection, the context menu, the keyboard shortcut, or "改选中的" in the side panel), the extension reads the following from the current document:

  • the text you selected;
  • the document title and URL;
  • the document text and structure (headings, lists, tables); for long documents (roughly 20,000+ characters) only the outline and the part around the selection;
  • the content of embedded spreadsheets that are loaded on the page (up to 100 rows × 30 columns each);
  • up to 8 images in or near the section of the selection (longest side up to 1920 px);
  • the instructions and follow-up requests you type in the side panel.

Images are downloaded inside the document page using your existing document session. The extension does not read your cookies, sign-in tokens or passwords.

The extension does not read your browsing history, other tabs, other websites, form inputs, keystrokes or location. The script on document pages only shows a floating button when you select text; the selection, scroll and Esc-key events it listens to are used only to show or hide that button and are neither recorded nor sent.

3. How the data is used and where it goes

StepWhat happens
Extension → local serviceThe data in section 2 is sent to the companion service on your computer via http://127.0.0.1:19930. This step does not go over the internet.
Local service → AI CLIThe service saves the images temporarily in your computer's temp folder (/tmp/xiefangan/ on macOS, %TEMP%\xiefangan\ on Windows), then starts the AI command-line tool you chose and gives it the content and instructions.
AI CLI → AI providerThe AI tool uses your own account to send the content to the AI provider you are signed in to (for example Anthropic, OpenAI or Tencent) to generate suggestions. How that data is transmitted, stored and used is governed by that provider's terms and privacy policy, not by this extension.
ResultSuggestions travel back from the AI tool → local service → side panel. You decide whether to copy them.

This data is used only to fulfil your current rewrite request and for no other purpose.

Please note:

  • The AI command-line tool runs with your own configuration. Depending on its own capabilities it may read files on your computer relevant to the task (such as memory or instruction files you set up for it) or search the web to check facts, just as when you use it in Terminal (macOS) or PowerShell (Windows). The service runs Codex in a read-only sandbox and allows WorkBuddy only read, search and web-lookup tools; Claude Code uses your local Claude Code permission settings.
  • If Codex or WorkBuddy is not signed in yet, the service opens that tool's official sign-in page or window. Sign-in is handled by the tool itself; neither the extension nor the service sees your credentials.

4. Where data is stored and for how long

  • The companion service itself: the install command places the service (a Node.js script, a rules file and local settings) in ~/Library/Application Support/XieFangAn/ on macOS and registers it as a launchd agent that starts at login (~/Library/LaunchAgents/com.xiefangan.bridge.plist). On Windows it is placed in %LOCALAPPDATA%\XieFangAn\, and a XieFangAn.vbs file in your Startup folder runs it in the background at sign-in. The uninstall command removes all of these.
  • Browser local storage (chrome.storage.local): only two preferences — the AI tool you chose and the model chosen for each tool.
  • Browser session storage (chrome.storage.session): the just-captured selection is held here briefly and cleared as soon as the side panel receives it; the browser also clears it when it closes.
  • Temporary images on your computer: under /tmp/xiefangan/ on macOS and %TEMP%\xiefangan\ on Windows (one folder per document). macOS cleans this periodically or on restart; on Windows, Disk Cleanup can clear it. You can delete it at any time.
  • Local service log: ~/Library/Logs/xiefangan-bridge.log on macOS, %LOCALAPPDATA%\XieFangAn\logs\bridge.log on Windows, recording only the request time, the AI tool used, the document ID, the first 40 characters of your instruction, and the source of connection checks (request method, the calling extension's ID, and whether it was accepted), for troubleshooting. It is not sent anywhere.
  • WorkBuddy login script: if you choose WorkBuddy and are not signed in, the service writes a small script (to /tmp/xfa-login/ on macOS, %TEMP%\xfa-login\ on Windows) that only launches the sign-in flow. It contains no account information.
  • The AI tool's own records: the AI command-line tool may keep conversation history on your computer in its own way (used for follow-ups), and the provider may retain data under its own policy. Refer to that tool's and provider's documentation.

The developer has no server and does not receive or store any of your document content or usage data.

5. Sharing with third parties

  • The developer does not sell, rent, trade or share your data with any third party.
  • The extension uses no analytics, advertising, crash-reporting or tracking services.
  • The only outbound transfer happens after you trigger the extension: your own AI command-line tool, signed in with your account, sends the content to the AI provider you chose. This is required for the extension's single purpose. If you do not want some content sent to an AI provider, do not use the extension on it.
  • When you install or uninstall the companion service, your computer downloads the scripts and the service program from the website hosting them (GitHub Pages), which may keep access logs (such as IP addresses) under GitHub's privacy statement. The extension itself does not contact that website during use.
  • Third-party download (Windows only, only when needed): when installing on Windows, if no usable Node.js (required to run the service) is found, the install command downloads the official portable Node.js build (a zip archive; no system settings changed, no administrator rights needed) from npmmirror.com or nodejs.org, for use by the companion service only. Those sites may keep access logs (such as IP addresses) under their own policies. No other third-party software is downloaded, and Node.js is never downloaded automatically on macOS.

6. Your choices and how to delete data

  • Nothing is read unless you trigger it: the extension never reads documents automatically.
  • Disable or remove the extension at edge://extensions/; the preferences stored in the browser are removed with it.
  • Uninstall the companion service:
    • macOS: run the uninstall command from the website in Terminal (curl -fsSL https://liyubuke.github.io/xiefangan/uninstall.sh | bash). It stops and removes the service, its login item, its log, the temporary images under /tmp/xiefangan/ and the login script under /tmp/xfa-login/.
    • Windows: run irm https://liyubuke.github.io/xiefangan/uninstall.ps1 | iex in Windows PowerShell. It stops and removes the service, %LOCALAPPDATA%\XieFangAn\ (including its log and any portable Node.js downloaded during install), XieFangAn.vbs in your Startup folder, the temporary images under %TEMP%\xiefangan\ and the login script under %TEMP%\xfa-login\.
  • Delete temporary images manually: on macOS run rm -rf /tmp/xiefangan in Terminal; on Windows run Remove-Item -Recurse -Force "$env:TEMP\xiefangan" in PowerShell.
  • Data held by your AI provider: view or delete it using the tools that provider offers.

7. Security

  • The companion service listens only on 127.0.0.1, is not exposed to your local network or the internet, and only accepts requests from this extension; ordinary web pages cannot call it.
  • The extension loads no remote code; all code ships in the extension package and is not obfuscated.
  • The extension is read-only with respect to your documents: it never modifies, deletes or writes back to them.

8. Children

This extension is intended for workplace writing and is not directed at children under 13. We do not knowingly collect personal information from children.
